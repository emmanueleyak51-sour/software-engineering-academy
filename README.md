# Nigerian Computing Academy

A standalone static learning prototype for learners exploring computing and technology-related degree pathways offered by Nigerian universities.

## What is included

- An onboarding choice of 19 computing and closely related programme pathways.
- Typical UTME minimum duration estimates and a year-by-year orientation map for each pathway.
- Search and category filtering, saved local course choice, and a JAMB IBASS reference section.
- Existing guided lessons, practice, quizzes, projects, study notes, progress, and local data backup.
- A visible notice explaining that the existing lesson library is strongest in shared computing foundations and Software Engineering; it is not a complete university syllabus for every selected programme.

## Run it

Keep `index.html` and `programmes.js` in the same folder. Open `index.html` in a modern browser, or publish the folder as a static site. The selected programme and learner progress are stored only in the browser's local storage in this prototype.

## Academic accuracy

The catalogue is an exploration aid, not an admission decision or official degree handbook. Programme titles and entry requirements vary by university. Duration labels are typical minimums for UTME planning; students should confirm the exact current programme, approved curriculum, duration, UTME subject combination, and Direct Entry placement in JAMB IBASS and with the institution.

## Production status

This is still a static prototype. It does not provide verified online accounts, a shared student database, real payment processing, institutional course approval, teacher/admin operations, or cloud-synced progress. Do not collect sensitive student information in this version.
